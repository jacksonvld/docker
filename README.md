# Contêineres e Docker

Repositório destinado a estudos, configurações e exemplos relacionados a contêineres Docker.

## Organização recomendada

- Uma pasta por serviço ou aplicação.
- Arquivos `compose.yaml` acompanhados de instruções de execução.
- Variáveis de configuração documentadas em `.env.example`, com dados fictícios.
- Credenciais reais fora do controle de versão.

## Segurança

Antes de executar qualquer exemplo, revise portas, volumes, redes, imagens e permissões. Não inclua senhas, tokens ou chaves no repositório.

> Este README descreve a finalidade geral. Os exemplos existentes não foram auditados integralmente.
